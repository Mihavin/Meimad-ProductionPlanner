# TV Dashboard

The Meimad Planner Server serves this read-only kiosk UI at `/tv-dashboard/` and its projection at `GET /api/v1/tv-dashboard`.

The dashboard is dependency-free and requires no separate web host or build step. Its no-scroll compact dark board displays one horizontal band per display-enabled active Machine: number/name and connection dot, Part Number, Work Order (`פק"ע` / `Заказ-наряд`) and Operation, Operation name, large textual execution state, authoritative completed/target part count, measured average cycle time with its sample count, and a thin progress bar. Idle bands explicitly show `No current operation`. Setup displays a percentage; after the connected CNC's first cycle start, production uses the Server-owned Production Run counter rather than elapsed-time inference. Pauses freeze progress at the pause time. It deliberately does not render part previews, conflicts, warnings, next/third jobs, host text, summaries, configuration, forms, edit controls, Edit Mode calls, or planning mutation code.

The richer dashboard projection remains Server-owned and continues to derive Machine status from authoritative planning state. The kiosk deliberately renders only the status result; it does not calculate or mutate planning state in the browser.

Open the Server URL in the kiosk browser, for example `http://planner-server:5080/tv-dashboard/`, and press **Full screen** (or configure the browser/operating system for fullscreen kiosk mode). Keep the Server bound only to the approved factory LAN interface.

The board (build `0.1.38`, concept C3 chosen by the owner on 2026-10-10) is a dark table banded by status: attention (paused, or CNC offline with a current operation), setup, in production, then completed/waiting/idle; `groupOf` in `app.js` decides the band from the projection's `statusCode`, `phase` and `connection.online` only. The page targets the browsers of factory TVs (Samsung Tizen ships Chromium 47-94): `app.js` is ES2015 only (no optional chaining, nullish coalescing, async/await, `replaceAll`, `padStart`, `URLSearchParams`), `styles.css` uses flexbox without CSS grid, custom properties, `clamp()`, `min()` or flex `gap`, and the script sizes the bands from the viewport. `index.html` carries a plain-ES5 error handler that writes a script error on the board instead of leaving it black. `TvDashboardApiTests` guards these constraints. When `DASHBOARD_BUILD` changes, change it in `app.js`, the `?v=` query strings in `index.html`, `TvDashboardService.cs` and the test together.

The Timeline tab remains embedded in the main window and offers a separate-window action. Both surfaces use the same read-only Timeline view model and committed Server projection. Opening, refreshing, or closing the separate window cannot assign, reorder, start, suspend, finish, or otherwise mutate planning data.
